# PROBIFLIGHT

## Objectif
PROBIFLIGHT vise à devenir une application desktop installable sur PC (puis macOS/Linux) pour :
- détecter et configurer la gamme des cartes Arduino (Uno, Mega, etc.) et d’autres cartes du marché ;
- reconnaître et configurer des périphériques (moteurs pas‑à‑pas, encodeurs incrémentaux/rotatifs, etc.) ;
- se connecter à Microsoft Flight Simulator et X‑Plane.
